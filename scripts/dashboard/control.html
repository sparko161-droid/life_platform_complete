Правила создания / готовности новой задачи

  • Новая работа должна иметь источник: roadmap requirement или discovery.
  • Новая задача сначала BACKLOG; READY разрешён только после анализа и architecture check.
  • READY требует primary, независимого reviewer, gate owners, acceptance criteria, test strategy и явной классификации зависимостей.
  • Контрактная зависимость может быть FROZEN/VALIDATED; implementation dependency должна стать DONE до интеграции.
  • Blocking discovery, security finding или unresolved human decision блокируют READY.
  • Расширение scope исходной задачи запрещено: создаётся отдельная traced task.
