# Экран: профиль ребёнка

**ID:** P-CHILD-PROFILE
**Прежний ID:** UX-CHI-01 (выведен из употребления, см. `docs/ux/screen-id-scheme.md`)
**Владелец:** Child Experience Lead + UI/UX Lead

## Назначение
Показывать ребёнку его игровой образ и развитие.

## Содержимое
- Аватар.
- Имя или выбранное игровое имя.
- Уровень.
- Опыт до следующего уровня.
- Серии.
- Достижения.
- Навыки в игровом представлении.
- Доступные награды.

## Переходы
«Мои задания» → день ребёнка.
«Мои достижения» → коллекция.
«Мои награды» → витрина наград.
«Друзья» → социальный раздел.

## Правила
- Не показывать деньги родителей без отдельного разрешения.
- Не сравнивать ребёнка с детьми без активного соревнования.
- Все формулировки короткие и понятные.

## Состояния
Новый ребёнок без истории, обычный профиль, нет соединения, временно недоступная статистика.

## Проверка
Профиль не должен требовать загрузки закрытых данных и открывается на любом поддерживаемом устройстве.
