# Экран: конструктор заданий

**Канонический контракт:** `P-TASK-BUILDER` — `docs/ux/screens/parent-task-builder.md`
**Прежний ID:** UX-PAR-03 (выведен из употребления, см. `docs/ux/screen-id-scheme.md`)

> Этот документ — ранний продуктовый набросок. Он сохранён как источник
> продуктовых требований, но идентичность экрана и его контракт задаёт
> `parent-task-builder.md`. При расхождении побеждает контракт.

**Владелец:** UI/UX Lead + Task Domain Lead

## Назначение
Создать или изменить задание без программирования.

## Шаги
1. Название и описание.
2. Кому назначить.
3. Когда выполнять.
4. Как ребёнок должен выполнить.
5. Как подтвердить результат.
6. Какая награда.
7. Нужно ли участие родителя.
8. Предпросмотр для ребёнка.
9. Сохранить или назначить.

## Действия
«Сохранить черновик».
«Посмотреть глазами ребёнка».
«Назначить».
«Отменить».

## Состояния
Черновик, проверка настроек, ошибки правил, готово к назначению, опубликовано.

## Правила
- Рекомендации системы не обязательны.
- Изменение семейной копии не меняет общий шаблон.
- Нельзя создать противоречивые условия без понятного предупреждения.
- Денежная награда требует отдельного разрешения.

## Проверка
Родитель может собрать простое задание и составное задание без изменения кода.
