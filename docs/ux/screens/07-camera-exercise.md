# Экран: упражнение с камерой

**ID:** UX-CHI-05
**Владелец:** Computer Vision Lead + Child Experience Lead

## Назначение
Превратить физическое упражнение в игровую миссию с понятной обратной связью.

## Экран
- Игровая цель.
- Живое изображение с камеры.
- Точки и линии тела.
- Большой счётчик выполнения.
- Полоса прогресса.
- Подсказка по положению тела.
- Кнопки «Пауза» и «Завершить».

## Подготовка
Проверить разрешение камеры и видимость нужных частей тела.
Показывать ребёнку простые подсказки: «Отойди немного», «Встань ровнее», «Я не вижу ноги».

## Выполнение
Каждое подтверждённое повторение сразу отражается на экране.
Неверное движение не должно увеличивать счётчик.

## Завершение
Цель достигнута → победная анимация → результат → награда.
Неуверенный результат → предложение повторить или передать на проверку родителю.

## Приватность
Исходная видеозапись не сохраняется по умолчанию. На сервер отправляется только результат, необходимый для задания и статистики.
