# Parent — Dashboard

**Screen ID:** P-DASH
**Owner:** Frontend Lead
**Review:** Product + QA + Security

## Purpose
Give the parent a fast understanding of the child's day, pending decisions, progress and social activity.

## Data
Today completion summary, approvals, streaks, rewards, recent achievements, child invitations and important notifications.

## Actions
«Проверить задания» → approvals; «Задания» → builder/list; «Награды» → reward center; «Семья» → family settings; «Друзья» → parent social.

## States
Normal, no activity, child offline, pending approvals, notification overload, multiple children.

## Privacy
Never expose another family's private data. Money values are shown only to authorized parents.

## Acceptance
Parent can identify what needs attention in under one screen and every visible action has a documented command/query and destination.
