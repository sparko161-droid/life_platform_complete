# Экран: друзья родителей

**ID:** P-SOCIAL
**Прежний ID:** UX-SOC-01 (выведен из употребления, см. `docs/ux/screen-id-scheme.md`)
**Владелец:** Social Lead + Parent Experience Lead

## Назначение
Помогать родителям знакомиться, находить общие интересы и постепенно объединять семьи.

## Содержимое
- Мои друзья.
- Возможные знакомства.
- Общие интересы.
- Достижения, которыми разрешено делиться.
- Общие семейные активности.
- Приглашения.

## Переходы
«Познакомиться» → профиль родителя.
«Добавить» → запрос на дружбу.
Принятый запрос → беседа родителей.
«Поделиться кейсом» → публикация выбранного результата.

## Правила
Детская дружба и дружба родителей независимы.
Не показывать лишние сведения о ребёнке.
Геолокация, деньги и закрытые семейные данные не являются частью публичного профиля.

## Состояния
Нет рекомендаций, есть совпадения, отправлен запрос, дружба активна, пользователь заблокирован.
