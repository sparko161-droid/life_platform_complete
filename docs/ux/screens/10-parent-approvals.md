# Экран: подтверждение выполнения

**Канонический контракт:** `P-APPROVALS` — `docs/ux/screens/parent-approvals.md`
**Прежний ID:** UX-PAR-04 (выведен из употребления, см. `docs/ux/screen-id-scheme.md`)

> Этот документ — ранний продуктовый набросок. Он сохранён как источник
> продуктовых требований, но идентичность экрана и его контракт задаёт
> `parent-approvals.md`. При расхождении побеждает контракт.

**Владелец:** Parent Experience Lead + Verification Lead

## Назначение
Родитель проверяет задания, для которых требуется его решение.

## Содержимое
- Ребёнок.
- Задание.
- Что ребёнок отправил.
- Время выполнения.
- Подсказка, на что обратить внимание.
- Кнопки «Подтвердить» и «Попросить повторить».
- Поле для короткого комментария.

## Переходы
«Подтвердить» → результат → начисление положенной награды.
«Попросить повторить» → уведомление ребёнку с понятной причиной.

## Правила
Повторное подтверждение одной попытки не начисляет награду повторно.
Родитель не меняет историю задним числом; исправления создают отдельную запись.

## Состояния
Новая проверка, уже просмотрено, принято, требуется повтор, ошибка отправки.

## Проверка
После решения родитель видит обновлённую историю, а ребёнок получает понятное уведомление.
