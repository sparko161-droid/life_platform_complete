# Экран: выполнение и подтверждение задания

**ID:** C-VERIFICATION
**Прежний ID:** UX-CHI-04 (выведен из употребления, см. `docs/ux/screen-id-scheme.md`)
**Владелец:** Verification Lead + Child Experience Lead

## Назначение
Провести ребёнка через выбранный способ подтверждения.

## Основные режимы
- Фотография: подсказка → съёмка → просмотр → отправка.
- Видео: запись → просмотр → отправка.
- Голос: запись → прослушивание → отправка.
- Таймер: старт → выполнение → завершение.
- Счётчик: цель → текущее число → завершение.
- Проверка родителя: отправка результата → ожидание ответа.

## Состояния
Подготовка, выполнение, отправка, ожидание проверки, принято, нужно повторить, ошибка.

## Переходы
«Готово» → результат задания.
«Повторить» → текущий способ выполнения.
«Отменить» → карточка задания без потери данных, если они ещё не отправлены.

## Правила
Ребёнку всегда показывается понятная причина, что делать дальше.
Технические коды и названия методов не отображаются.

## Проверка
Повторная отправка одной и той же попытки не должна создавать двойную награду.
