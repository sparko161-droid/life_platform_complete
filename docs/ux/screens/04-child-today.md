# Экран: день ребёнка

**ID:** UX-CHI-02
**Владелец:** Child Experience Lead + Frontend Lead

## Назначение
Главный экран ребёнка: понятный игровой план дня.

## Содержимое
- Приветствие.
- Текущая серия.
- Прогресс дня.
- Обязательные задания.
- Дополнительные задания.
- Квест дня.
- Доступные награды.

## Карточка задания
Название, короткое описание, срок, награда, способ выполнения.
Кнопка действия: «Начать» или «Продолжить».

## Переходы
«Начать» → карточка задания.
Завершённое задание → обновление дня без потери позиции.
«Награда» → витрина наград.
«Друзья» → социальный раздел.

## Состояния
Новый день, часть заданий выполнена, день завершён, нет соединения, ошибка загрузки.

## Правила
- Не показывать внутренние названия механик.
- Не перегружать ребёнка большим количеством задач.
- Выполненные базовые привычки не должны исчезать без истории.

## Проверка
После выполнения задание меняет состояние и ребёнок понимает, что делать дальше.
