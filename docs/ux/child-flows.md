# Child UX Flows

**Owner:** Child Experience Lead

## Core loop
Open app → see Today board → choose mission → read/see instructions → start → verify → celebration → progress/reward → next mission.

## Task proof
Manual: complete → done state.
Parent approval: complete → waiting state → parent decision.
Photo/video/audio: capture → preview → upload/process → verification state → result.
Camera exercise: framing → ready check → live overlay/counter → result.

## Social
Friend invite is parent-controlled. Child sees only approved friends and safe profile fields.

## Recovery
Network loss preserves local draft/progress where supported. Reopen resumes the current step or explains why it cannot.

## Motivation
Avoid long forms and negative failure screens. Corrective guidance is immediate and actionable.

## Accessibility
Large tap targets, readable type, sound/text alternatives, reduced-motion mode and no information conveyed by color alone.
