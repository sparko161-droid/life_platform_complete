# Design System Foundation

**Owner:** UI/UX Lead
**Review:** Child Experience, Frontend Lead

## Shared primitives
Buttons, inputs, cards, task cards, progress bars, badges, avatars, dialogs, bottom sheets, navigation, toasts, media capture states.

## Child visual language
Large targets, clear hierarchy, playful motion, character/game feedback, short text and strong status cues.

## Parent visual language
Dense but calm information layout, filters, history, controls, permissions and explainable status.

## States
Every interactive component defines default, hover/focus, pressed, disabled, loading, success, error and permission-restricted states where applicable.

## Accessibility
Keyboard navigation on web, screen-reader labels, touch target minimums, reduced motion, contrast and non-color status cues.

## Rule
Domain-specific styling can extend shared primitives but must not duplicate behavior or state logic.
