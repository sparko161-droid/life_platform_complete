# Каталог пользовательских путей

**Владелец:** Journey Agent
**Проверка:** QA Lead + UI/UX Lead

## Основные пути

### Родитель
`Регистрация → Семья → Ребёнок → День ребёнка → Подтверждение → Награда → История`.

### Второй родитель
`Приглашение → Принятие → Выбор роли → Доступ к семье`.

### Ребёнок
`Вход → День → Задание → Выполнение → Проверка → Результат → Следующее задание`.

### Камерное упражнение
`Задание → Разрешение камеры → Подготовка → Готово → Счётчик → Цель → Результат`.

### Социальный путь
`Родительское знакомство → Одобрение → Дружба → Беседа → Кейсы → Семейная активность`.

### Ребёнок и друг
`Разрешённый друг → Профиль → Беседа → Приглашение в игру → Комната → Результат`.

### Награда
`Условие → Доступна → Подтверждение получения → Выдана → Использована/истекла`.

### Обучение
`Задание → Занятие → Результат → Профиль развития → Рекомендация → Решение родителя → Новая активность`.

## Правило связности
Каждый путь имеет начало, условия входа, все состояния, успешный результат, отказ, повтор и выход. У каждого перехода должен быть определён источник данных, команда, событие и следующий экран.

## Проверка
Сквозной тест должен проходить путь без ручного изменения базы данных.
