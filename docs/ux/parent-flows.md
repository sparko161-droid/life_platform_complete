# Parent UX Flows

**Owner:** UI/UX Lead
**Review:** Product Manager, Security

## Daily
Dashboard → child → today → pending approvals → reward/history.

## Task builder
New task → choose template/type → configure schedule → verification → reward → preview → save draft → assign → notification.

## Family
Family → invite parent → role → invite status → acceptance → capability summary.

## Social
Discover → shared interests/case → connection request → accepted → parent chat → optional family relationship.

## Child safety
Child profile → communication policy → chat visibility → allowed contacts → devices → notification rules.

## AI
Describe goal → AI draft → sources/reasoning summary → editable plan → approve → publish. AI never silently activates a plan.

## Rule
Destructive/reward/permission actions require confirmation and a clear post-action audit trail.
