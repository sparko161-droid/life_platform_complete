# Privacy Baseline

**Status:** Foundation
**Owner:** Security Lead + Legal Advisor

## Default posture

Child data is private.
Collect minimum necessary information.
No public child discovery by default.

## Media

Photos, audio and videos use private access URLs/authorization. Raw exercise camera frames are not stored by default.

## Chat

Access is controlled by policy. Parent visibility can be FULL, METADATA_ONLY or DISABLED.

## Data lifecycle

Define retention, deletion, export and account closure rules before production.

## Legal baseline

Russian launch requires a dedicated review of applicable personal-data, child-safety and information-product requirements. This document is not legal advice.

## Security controls

- least privilege
- MFA for privileged staff where supported
- secret management
- rate limiting
- audit logs
- dependency scanning
- secure headers
- API authorization on every sensitive operation
