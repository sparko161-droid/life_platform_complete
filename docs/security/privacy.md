# Privacy Baseline

**Status:** Foundation
**Owner:** AI CTO
**Depends on:** MASTER_SPEC
**Related:** MASTER_SPEC


## Default posture
Child data is private and minimized. Collect only data required for product function.

## Media
User-submitted photos/audio/video use private authorized access. Exercise camera frames are processed locally by default and not retained.

## Social data
Visibility is explicit and per category. Money, direct messages, device data and location are sensitive by default.

## Lifecycle
Support access, correction where applicable, deletion, export and retention rules. Define retention schedules before production.

## Russia launch
Legal review must cover applicable personal-data, child-safety and information-product requirements. This document is engineering guidance, not legal advice.
