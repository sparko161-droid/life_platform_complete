# Child Safety

**Status:** Foundation
**Owner:** Safety Lead

## Social rules

Child accounts do not freely discover unknown children.
Friendship requires controlled approval.

## Messaging

Support text, voice and short video circles, but pass content through moderation and rate limits.

## Reporting

Every social object has a report/block path appropriate to the user role.

## Moderation pipeline

Message/media → safety checks → allow/restrict/block/review.

## Parent controls

Parent can enable/disable channels, control friend access and select chat visibility policy.

## Abuse cases

Design for bullying, harassment, unwanted contact, spam, adult content, threats, personal-data sharing and impersonation.

## Human review

High-risk moderation cases must be reviewable by authorized moderators with audit trail.
