# Rules Engine

**Owner:** Domain Architect

`EVENT → CONTEXT → CONDITIONS → ACTIONS`.

## Inputs
Task completion, streak reached, quest progress, friendship events, game results, learning results, schedule events.

## Conditions
Age band, task/category, count, streak, time, skill, prerequisite, parent policy, feature flag.

## Actions
Grant XP/coins, unlock achievement, create reward eligibility, advance quest, notify, create next task, update skill progress.

## Safety
Rules cannot bypass permissions, create money transfers, change child privacy or publish public content. Such actions require approved application services.

## Acceptance
The same rule executes consistently from Web, mobile, integrations and scheduled jobs without duplicating business logic.
