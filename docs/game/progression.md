# Progression model

**Owner:** Game Design Lead

Progression is layered: `XP → Level`, `Coins → spendable game economy`, `Skills → capability progress`, `Streaks → consistency`, `Achievements → milestones`.

## Rules
- XP is not money and is never deducted for ordinary mistakes.
- Streaks may break without punitive loss of earned XP.
- Skill scores are descriptive game metrics, not psychological diagnoses.
- Difficulty may adapt only within parent-approved bounds.
- Rewards should diversify motivation rather than create mandatory payment loops.

## Acceptance
A child can understand current progress, next milestone and available rewards without seeing private parent financial data.
