# Product Vision

**Status:** Foundation
**Owner:** Product / Human Architect

## Promise

«Прокачивай настоящую жизнь».

## Primary loop

Task → Completion → Verification → XP/Reward → Progress → New Challenge.

## Secondary loops

- Friends → Competition → Cooperative games.
- Parents → Cases → Family friendships.
- Learning → Skill progress → Game unlocks.
- AI → Personalization → Parent approval.

## Audience

Русскоязычные семьи, первоначально ориентированные на РФ. Ребёнок обычно 4–13 лет; первая продуктовая точка — дошкольный/младший школьный возраст.

## Product roles

Child: player.
Parent: family operator.
Platform Admin: safety/content/operations.
Human Architect: product + architecture owner.

## North Star

Количество дней, когда ребёнок возвращается к «Жизни» и добровольно выполняет значимые активности.

## Product principles

- Не превращать каждое полезное действие в деньги.
- Давать ребёнку понятную обратную связь.
- Не делать соревнование единственным источником мотивации.
- Родителю снижать нагрузку, а не добавлять ещё один диспетчерский интерфейс.
- Сохранять баланс между автоматизацией и участием родителя.
