# AI Avatar

**Owner:** AI/ML Lead
**Review:** Child Safety, UX, Security

## Purpose
Provide a playful child-controlled avatar that can represent progress, achievements and game identity across supported surfaces.

## Creation
Avatar generation uses parent-approved inputs and age-safe generation policies. No public likeness generation is enabled by default.

## Separation
Avatar assets are separate from verification media and the child's identity record. A child may reset or replace an avatar.

## Safety
No sexualized, humiliating, violent or realistic transformation prompts are accepted. Public sharing uses the avatar identity, not private child media.

## AI boundary
Generated output is content, not authority. Moderation and policy checks run before publication or social sharing.

## Clients
The canonical avatar definition is server-owned; clients render it through platform adapters so Web, Android and iOS remain consistent.
