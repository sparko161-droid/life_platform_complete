# Competition model

**Owner:** Game Design Lead
**Review:** Child Safety + QA

Competition is optional. Default child ranking is private.

## Modes
- Personal Best: child improves own result.
- Friendly 1v1: approved friends only.
- Team: cooperative score.
- Family: household challenge.
- Progress: compare improvement, not absolute ability.

## Metrics
Use age-banded, normalized metrics. Never expose money or private rewards as a leaderboard metric by default.

## Safety
No unrestricted matchmaking. Parent permission is required for child participation in competitive social features.

## Acceptance
A child can join an approved challenge, see safe progress, finish it and receive the configured reward without exposing private family data.
