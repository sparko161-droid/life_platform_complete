# Child Daily Loop

**Owner:** Child Experience Lead
**Review:** Product, QA, Safety

## Loop

`Open day → orient → choose/receive task → act → verify → feedback → reward → next task → day summary`.

## Rules

- Child always sees why a task exists and what is gained.
- Mandatory and optional work are visually distinct.
- The system must not create grind by unlimited repeatable rewards.
- Parent rules override recommendations.
- A failed verification explains the next action; it does not shame the child.
- Daily load is age-aware and bounded.

## Day state

`NOT_STARTED`, `IN_PROGRESS`, `PAUSED`, `COMPLETED`, `PARTIAL`, `EXPIRED`.

## Completion

A day can be successful without 100% completion. Parent policy defines the success threshold.

## Acceptance

A child can finish, pause, resume and review a day without losing progress or receiving duplicate rewards.
