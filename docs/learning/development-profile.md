# Development Profile

**Owner:** Learning Lead
**Review:** Child Safety + Human Architect

Profile describes game/learning progress, not diagnosis.

## Dimensions
- literacy and communication
- numeracy and logic
- physical activity
- self-care and independence
- household responsibility
- collaboration and communication
- creativity

## Evidence
Each observation stores source, timestamp, activity, confidence and methodology version.

## Sources
Task results, learning sessions, parent observations and reviewed knowledge items.

## AI rule
AI may summarize patterns and propose practice. It must not diagnose, label a child or present uncertain inference as fact.

## Acceptance
Parent can inspect why a recommendation was made and disable the recommendation.
