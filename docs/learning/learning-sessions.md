# Learning sessions

**Owner:** Learning Lead
**Review:** AI Safety + QA

A learning session is a bounded activity that can be launched from a task, Alice or a game.

## Types
`VOCABULARY`, `READING`, `MATH`, `SPELLING`, `GENERAL_KNOWLEDGE`, `PRONUNCIATION`.

## Flow
`SESSION_ASSIGNED → STARTED → RESPONSE → FEEDBACK → COMPLETED`.

## Rewards
Learning may grant XP and skill progress. Money requires a separate parent-defined reward rule.

## AI
AI can generate questions from approved content sources. The session must carry the content/version used so results remain explainable.

## Acceptance
Parent can see what was learned, source/version, result and suggested follow-up without seeing internal model prompts.
