# AI Team Organization

**Status:** Foundation
**Owner:** Human Architect

## Human role

Human Architect / Product Owner owns final product decisions, architecture boundaries, priorities and high-impact trade-offs.

## AI hierarchy

Human Architect → AI CTO → domain leads → implementation agents → review agents.

## Core roles

1. AI CTO / Engineering Director
2. Product Manager
3. Roadmap / Priority Advisor
4. Chief Architect
5. Domain Architect
6. Architecture Reviewer
7. Backend Lead
8. Frontend Lead
9. Mobile Lead
10. Game Engine Lead
11. AI/ML Lead
12. Computer Vision Lead
13. Integrations Lead
14. UI/UX Lead
15. Child Experience/Game Design Lead
16. QA Lead
17. Automated Test Agent
18. User Journey/Exploratory Agent
19. Security & Child Safety Agent
20. Code Quality/Refactoring Agent

## Principle

Agents are not peers without hierarchy. Each has a defined responsibility and review scope.
