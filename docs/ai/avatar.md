# AI Avatar

**Owner:** AI/ML Lead
**Review:** Child Safety + UX

Avatar is a game identity, not a public copy of the child.

## Lifecycle
`DRAFT → PARENT_APPROVAL → ACTIVE → ARCHIVED`.

## Inputs
Style, theme, optional child-provided choices and approved media. Exact likeness is optional and disabled by default.

## Rules
- Parent controls creation and publication.
- Generated content is moderated before social use.
- Private source media is not automatically exposed with the avatar.
- Avatar assets are versioned so future model changes do not silently alter identity.

## Acceptance
Child can use the avatar in the game, while parents control publication and privacy.
