# Knowledge Base

**Status:** Foundation
**Owner:** AI CTO
**Depends on:** MASTER_SPEC
**Related:** MASTER_SPEC


## Purpose
Store evidence-backed material for age-appropriate recommendations, learning activities, family routines and product guidance.

## Structure
Source → citation → topic → age range → skill → evidence note → review status → version.

## Governance
Content team/experts review high-impact developmental guidance. AI cannot invent a source claim.

## Retrieval
Use metadata filters before semantic retrieval. Child age and parent preferences are policy inputs, not diagnosis.

## Versioning
Recommendations reference the knowledge version used so results remain explainable.
