# MAX Integration

**Status:** Planned
**Owner:** Integrations Lead

## Surfaces

- Bot
- Mini App

## Architecture

MAX Bot/Mini App → MAX Adapter → Life API.

## Rules

MAX authentication is external identity metadata linked to a Life account. Business permissions remain controlled by Life.

## Candidate features

Parent task management, reminders, family chat entry points, lightweight dashboards and links to full app.

## Operational note

Current MAX developer documentation requires reviewing account/organization prerequisites and current API limits before production integration.
