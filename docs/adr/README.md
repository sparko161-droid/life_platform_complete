# ADR Rules

Architecture Decision Records explain decisions, alternatives and consequences.

## File name

`ADR-XXXX-short-name.md`

## Required sections

- Status
- Context
- Decision
- Alternatives
- Consequences
- Reversal plan

## Mandatory ADR triggers

- core stack change
- database change
- event transport change
- mobile framework change
- public API versioning decision
- new cross-domain dependency
- new data ownership boundary
- major security/privacy decision
- production infrastructure model change
