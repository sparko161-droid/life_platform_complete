# Mechanics Gaps

**Owner:** AI CTO
**Review:** Human Architect

## High priority

- Daily-load calculation and estimation must become executable policy.
- Task Builder validation must cover contradictory verification and reward rules.
- Completion/reward idempotency needs integration fixtures.
- Parent/child chat policy needs complete state transitions for block/revoke.
- Challenge score settlement needs dispute/cancel rules.
- Learning evidence needs source/version lifecycle.

## Medium priority

- Case sharing needs privacy presets and redaction rules.
- Family activity suggestions need consent lifecycle.
- Screen-time coupons need redemption, expiry and conflict rules.
- Scenario engine needs timezone/DST and duplicate-assignment handling.
- Device capability fallback must be explicit per surface.

## Later

- Avatar progression and cross-device synchronization.
- Cooperative game reconnect/match recovery.
- Marketplace ranking and abuse prevention.
- AI-generated task provenance and user feedback loops.

## Rule

Each gap becomes an independent task only after triage. Existing scope is not silently expanded.
