# Roadmap Overview

**Owner:** Human Architect + AI CTO

## Delivery principles

- Build the smallest coherent slice.
- Freeze contracts before parallel implementation.
- Keep every phase releasable.
- Record discoveries instead of silently expanding scope.
- Prefer vertical slices over isolated technical demos.

## Phases

0. Engineering Workspace and AI Team
1. Identity, Family and Task Core
2. Game Loop and Child/Parent PWA
3. Mobile, Camera Verification and Device Layer
4. Social Graph, Messenger and Safety
5. AI, Learning and Integrations
6. Games, Marketplace and Community
7. Hardening, Beta and Production Scale

## Exit criteria

A phase exits only when acceptance, QA, security/safety, observability and documentation gates pass.

## Parallel work

Phase 1-2 can overlap after core contracts. Phase 3 begins once task verification contracts are stable. Social work can begin against the identity/permissions contract before Phase 3 closes.
