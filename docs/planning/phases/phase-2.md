# Phase 2 — Game Loop and PWA

## Objective
Make the daily routine feel like a game rather than a checklist.

## Core
XP, coins, levels, streaks, achievements, skills, quests, scenarios, child game shell, progress dashboard and configurable rewards.

## Streams
C1 economy/progression, C2 quests/scenarios, C3 child PWA/game UI, C4 parent dashboard, C5 analytics/fairness.

## Mechanics
Personal goals, daily mission board, streak milestones, 7/10/N-day reward paths, coupons for screen/device/family activities, optional competition and personal-best goals, age-aware daily-load limits, reward expiry and redemption conflict rules.

## Responsible
Game Design: economy/progression. Frontend: child experience. Backend: game services. Product/Child Experience: motivation balance. QA: progression/fairness.

## Contract gate
Completion events, progression transactions, reward decisions and challenge settlement rules are frozen before UX and analytics integration.

## Exit
A child can complete a coherent 7-day journey, see progress and unlock/redeem a configured reward; parent can audit, expire or change future rules without corrupting historical results.
