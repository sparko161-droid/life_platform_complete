# Phase 0 — Engineering Workspace and AI Team

## Objective
Create the system in which future work is traceable, reproducible and safely parallel.

## Outputs
Git/main protection, CI, local Docker stack, task registry, agent registry, worktree rules, contract versioning, seed fixtures, observability, security baseline, docs graph and AI orchestration protocol.

## Streams
A0 Git/CI, A1 infrastructure, A2 AI ops, A3 docs/ADR, A4 security.

## Responsible
AI CTO: coordination. Chief Architect: architecture. DevOps: environment. QA: gates/fixtures. Security: policy. Documentation: knowledge graph.

## Required tasks
P0-001 main/CI; P0-002 dev stack; P0-003 task registry; P0-004 worktrees/handoffs; P0-005 OpenAPI; P0-006 fixtures; P0-007 observability; P0-008 security; P0-009 Phase 1 contracts; P0-010 contract registry; P0-011 agent orchestration; P0-012 automated docs/traceability checks.

## Exit
Clean checkout runs checks and local infra. AI agents can claim, branch, hand off and review. Contract artifacts are versioned and discoverable. Human Architect sees only unresolved decisions.
