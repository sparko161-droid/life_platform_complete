# Case: Child Daily Loop

## Actor
Child age 6.

## Goal
Open the app, understand the day, complete tasks and receive progress.

## Path
Login → Today → choose task → execute → verify → reward → next task → streak/progress.

## Variants
Manual, parent approval, photo, video, timer, camera exercise.

## Success criteria
Child always understands what to do next and why it matters. No hidden dependency on parent except tasks requiring approval.

## Failure paths
Offline, rejected proof, expired task, insufficient permission, missing media.

## Metrics
Daily completion, session length, task abandonment, repeat visit, streak retention.

## Linked domains
Task, Verification, Economy, Notifications, Game.
