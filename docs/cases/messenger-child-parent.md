# Case: Messaging With Parent Controls

## Types
Text, voice, circle video, image, system, game invite.

## Policy
Every conversation is checked against server-side child communication policy.

## Parent visibility
FULL, METADATA_ONLY, DISABLED.

## Safety
Moderation, block, report, attachment limits, rate limits, age policy.

## Quality bonus
Text messages may yield language/communication XP only when quality rules prevent spam farming.
