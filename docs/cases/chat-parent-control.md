# Case: Child Chat → Parent Control

**Actors:** Child, Parent, Friend
**Domains:** Social, Messenger, Safety

1. Parents establish approved child friendship.
2. Child opens a protected conversation.
3. Message passes relationship and policy checks.
4. Moderation pipeline evaluates relevant content.
5. Parent visibility policy decides whether content or metadata is available.
6. Child can report/block without contacting support directly.
7. Revoke/block immediately changes future access.

## Important

Changing parent visibility never rewrites message ownership or storage. It changes protected-read authorization.
