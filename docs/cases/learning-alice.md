# Case: Learning Session → Development Profile → Alice

**Actors:** Child, Parent
**Domains:** Learning, Development Profile, AI, Alice

1. Parent activates an approved learning activity.
2. Child starts the session from Web, mobile or Alice.
3. Session records attempts/results, not a diagnosis.
4. Trusted result updates the Development Profile evidence stream.
5. AI may suggest the next practice within parent policy.
6. Alice can report status or start another approved session.
7. Parent can inspect the evidence basis and disable the recommendation.

## Safety

AI never silently changes child permissions, creates money rewards or publishes learning data.
