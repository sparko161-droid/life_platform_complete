# Case: Parent Family Onboarding

## Actor
New parent.

## Path
Register → create family → create child → select age → starter pack → customize → invite second parent.

## Success criteria
Parent can reach first assigned task without contacting support or editing the DB.

## Required controls
Roles, child profile, visibility defaults, reward defaults, communication policy.

## Recovery
Duplicate email, expired invite, second parent already linked, child profile archived.

## Metrics
Time to first task, starter-pack acceptance, second-parent invite rate.
